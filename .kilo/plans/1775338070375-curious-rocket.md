# Process Section Redesign - Plan

## Current Layout Issues
The diagonal layout (lines 159-258) has:
- Large negative margins (`md:-mt-32`) causing awkward spacing
- Horizontal offset (`md:ml-[25%]`, `md:ml-[50%]`, etc.) that doesn't render well
- Mobile shows simple vertical stack with no visual interest
- Connection lines don't align properly

## Proposed Layout Options

### Option A: Horizontal Timeline Cards (Recommended)
A horizontal row of cards with:
- Connected by a visual timeline line/dots
- Each card has number indicator, image, title, description
- Hover effects with scale/glow
- Responsive: horizontal scroll on mobile, row on desktop
- Clean, professional, predictable

### Option B: Alternating Split Layout
Cards alternating left/right:
- Image on one side, text on the other
- Connected by vertical timeline
- Works well on both mobile (stacked) and desktop (alternating)
- More content-focused

### Option C: Numbered Big Cards
Large prominent cards:
- Giant phase number as background element
- Each card is visually distinct
- Horizontal layout with equal spacing
- Modern SaaS aesthetic

### Option D: Interactive Accordion
Expandable sections:
- Only one phase expanded at a time
- Saves vertical space
- Engaging interaction
- Good for mobile

---

**Selected: Option A** - Horizontal Timeline Cards

## Implementation Plan

### Structure
- Container with centered layout, horizontal scrolling on mobile
- 4 cards in a row with equal width
- Visual timeline line connecting all cards
- Numbered circles on the timeline

### Card Design
- Image/video at top (rounded corners)
- Phase badge/label
- Title (bold, large)
- Description (2-3 lines)
- Subtle hover effects (scale up, shadow glow)

### Responsive Behavior
- Mobile: horizontal scroll or vertical stack
- Desktop: horizontal row with timeline

### Code Changes
- Keep existing data array (Discovery, Design, Development, Launch)
- Redesign the map function to render cards in a row
- Add timeline connector elements between/above cards
- Ensure proper spacing and alignment
