# Plan: Convert Blog Content from Markdown to HTML/TSX

## Goal
Convert all blog post content in constants.tsx from Markdown syntax (###, **, etc.) to proper HTML/TSX tags so the content renders as HTML instead of requiring Markdown parsing.

## Current State Analysis
- Blog content is stored as strings in BLOG_POSTS array in constants.tsx
- Content uses Markdown syntax: # for headers, ** for bold, * for italic, - for lists, etc.
- Presumably the BlogPostDetail component uses a Markdown renderer to display this content
- User wants to eliminate Markdown parsing and use direct HTML rendering

## Implementation Steps

### Step 1: Identify All Markdown Syntax Used
- Headers: #, ##, ###, ####
- Bold: **text**
- Italic: *text*
- Lists: - item, numbered lists
- Links: [text](/url)
- Line breaks and paragraphs

### Step 2: Create HTML Equivalent Mapping
- # → <h1>
- ## → <h2>
- ### → <h3>
- **text** → <strong>text</strong>
- *text* → <em>text</em>
- - item → <li>item</li> (wrapped in <ul>)
- 1. item → <li>item</li> (wrapped in <ol>)
- [text](/url) → <a href="/url">text</a>

### Step 3: Convert Each Blog Post Content
Convert all 6 blog posts one by one, replacing Markdown with HTML tags while preserving:
- Content structure and readability
- Internal links to /contact and /services
- Proper nesting and formatting
- Nigerian business context and CTAs

### Step 4: Update Blog Display Component (if needed)
Check if BlogPostDetail.tsx needs modification to render HTML instead of Markdown. May need to:
- Remove markdown parser dependency
- Add dangerouslySetInnerHTML or similar for HTML rendering
- Ensure proper styling of HTML elements

### Step 5: Fix Spacing and Formatting Issues
Address spacing problems in the blog content by:
- Ensuring proper paragraph margins (may need custom CSS)
- Adding adequate spacing between sections
- Adjusting the prose classes for better readability
- Adding proper spacing between elements

### Step 6: Test and Validate
- Build the project to ensure no compilation errors
- Test blog rendering to verify HTML displays correctly with proper spacing
- Check that links, formatting, and styling work properly

## Potential Challenges
- Ensuring proper HTML structure and nesting
- Maintaining responsive design with HTML elements
- Handling any special characters or encoding
- Making sure internal links work correctly
- Achieving proper spacing and readability with HTML elements
- Ensuring prose classes provide adequate spacing between paragraphs and sections
